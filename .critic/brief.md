# Brief

Frozen once the build starts. Critics score against this file, not their taste. Where the user said "you decide", the decision is written here and never revisited.

- **What I'm building:** app — a static, client-side interactive education website (single page, five screens).
- **One-line description:** "Data Detective: Can You Trust This Claim?" — a 10–15 minute investigation for ~15-year-olds that teaches three checks (graph framing, sampling bias, correlation vs causation) through manipulable synthetic data, ending with the learner writing a cautious evidence-based conclusion. Built for a Taskmarket bounty (task 0x95c8e16d…317fe, 4 USDC, one winner, judged on a 100-point rubric: educational correctness & clarity 25, age suitability 25, interactive learning & feedback 25, usability & accessibility 15, technical quality & reproducibility 10).
- **Primary goal / success metric:** a Year 11 learner completes all three activities with meaningful input, receives specific feedback, and writes a claim + supporting observation + limitation in the case file — and a rubric judge finds no educational error, no missing deliverable, and no accessibility failure. ← every decision serves this
- **Audience:** ~15-year-olds (allowing for individual differences), on phones (360px), tablets (768px) and laptops (1280px); they care about not being patronised, not being shamed, and finishing in one sitting. Secondary audience: the teacher reading EDUCATOR_GUIDE.md and the bounty judge reading TEST_REPORT.md.
- **Scope / pages or parts:** screens `start`, `a1` (graph framing), `a2` (sampling), `a3` (correlation + headline builder), `summary` (case file), plus the persistent evidence notebook; documents README.md, EDUCATOR_GUIDE.md, TEST_REPORT.md, LICENSE, THIRD_PARTY.md, data/ (JSON + DATA_DICTIONARY.md), tests/ (Node, no deps), a public GitHub Pages preview.
- **Stack / tools:** plain HTML/CSS/JS, no framework, no build step, no runtime network requests; inline SVG charts; localStorage for progress; a self-hosted OFL web font (Atkinson Hyperlegible) for readability; served by any static server (documented: `python -m http.server` and `node serve.mjs`).
- **Brand / style feel:** investigative, calm, precise, respectful, modern-editorial (a case file, not a cartoon).
- **Must-haves (from the bounty brief):** three required activities with the listed learner inputs and outcomes (axis manipulation with identical statistics; biased vs random sampling with population comparison and reproducible draws; stratified correlation with a justified conclusion and a new fictional headline combining ≥2 issues); evidence notebook; obvious start, onboarding, progress, completion summary with next-practice suggestion; demonstration + guided practice + fresh application; immediate specific feedback, ≥1 hint per activity, unlimited retry; reset/replay without reload; progress only in memory/localStorage with explanation and reset; prerequisites/objectives/adaptations and ≥2 reputable references in the educator guide; works at 360/768/1280 with no clipped controls or horizontal scroll; semantic controls, visible keyboard focus, accessible names, keyboard access to every core action, non-drag alternatives, text/table alternative to every chart; WCAG 2.2 AA contrast, ≥44px targets, non-colour-only feedback, reduced-motion support; every headline/person/organisation fictional and labelled; bundled synthetic data with labels, units, provenance and dictionary; calculations and charts use the same data; graceful handling of refresh, repeated inputs, invalid state; complete editable source, exact serve commands, tests that actually run, MIT licence, attribution.
- **Must-avoid:** login, wallet, payment, email, child name or personal data; ads, purchases, analytics/tracking, open chat, social feeds, uploads; runtime generative-AI chat, remote grading, external paid API; flashing, forced animation, autoplay audio, audio-only information; shaming, punishing, pressuring or ranking a child; timers; real-world medical/political/sensitive claims; implying real scientific findings; claiming validated learning gains; placeholder text, empty screens, dead buttons; child-directed outbound links; unlicensed assets; secrets or env files.
- **References / inspiration:** Seeing Theory (Brown), PhET, BBC Bitesize, Bartosz Ciechanowski, Nicky Case explorables; GAISE II (ASA) for pedagogy.
- **Existing project to learn from or edit:** none (data.js and index.html skeleton already drafted in this folder before the loop started; treat as round-0 work in progress).

## Decisions made from "you decide"

- Setting/brand: three fictional micro-worlds (Bramblewick Academy, Harrowgate College, Port Lumen) rather than one — each activity gets a self-contained story that names its fiction; reason: keeps each activity short and makes "everything here is fictional" easy to state per screen.
- Charts: hand-drawn inline SVG (no canvas, no library) — reason: accessible DOM, zero dependencies, deterministic screenshots.
- Font: Atkinson Hyperlegible (OFL, self-hosted woff2) — reason: designed for legibility; licence permits bundling; avoids CDN at runtime.
- Free-text answers: never auto-graded; presence/length feedback + self-review checklist + exemplar — reason: brief forbids pretending to understand prose.
- Persistence: localStorage key `dd_state_v1`, explained on the start screen, cleared by Reset — reason: brief allows local storage if explained and resettable.
- Screen routing: `?screen=<id>` query param (also drives static capture); `?static=1` adds `.static-mode` — reason: capture.mjs requirement and shareable direct links for the educator.
- Tests: Node built-in test runner (`node --test tests/`), loading data.js and the pure model functions — reason: zero dependencies, runs with one command.
- Hosting: GitHub Pages from the repo root under the owner's account — reason: free, public HTTPS, no server, independent of the source archive.

## Definition of done (5 lines, derived from the primary goal and must-haves)

1. All three activities and the case file work end to end at 360/768/1280 with keyboard only, with immediate specific feedback, a hint, and unlimited retry; identical numbers under any axis; reproducible sampling; stratified correlation.
2. No statistically false sentence anywhere; nuance explicitly taught (non-zero axis not automatically deceptive; bigger biased sample ≠ fix; association ≠ causation).
3. Authored accessibility: skip link, landmarks, :focus-visible everywhere, labels, live regions, chart tables, verified contrast ratios, reduced motion, no clipped controls.
4. Every deliverable in the brief exists and is truthful: source, README (serve commands, browsers, limitations), EDUCATOR_GUIDE (objectives, prerequisites, walkthrough, session length, differentiation, ≥2 references with URLs, limitations, offline follow-up), TEST_REPORT (every acceptance example → evidence + screenshots at three widths), passing tests, LICENSE, THIRD_PARTY, data dictionary + provenance.
5. Runs from a plain static server with zero runtime network requests, and the GitHub Pages preview matches the submitted archive.
